# Ecosystem — Satellite Subdomain Projects

Projects in the syrian.zone ecosystem that live **outside this repository**, served from their own subdomains. Distilled from the planning notes previously kept in `syrianzonepp/external_subdomain_projects.md`.

| Project | URL | Purpose |
|---|---|---|
| Answers | answers.syrian.zone | Community Q&A. This repo consumes it via the `/api/answers` widget endpoint on the Board. |
| Wasfatna (food) | food.syrian.zone | Syrian recipes site. Feeds the `/api/recipe-of-the-day` widget. |
| Laqta | laqta.syrian.zone | Open photo archive of Syria. |
| Codex | codex.syrian.zone | Tech articles/knowledge base. |

Related external-data pages inside this repo that render third-party datasets: `/syid`, `/sites`, `/syrian-contributors` (GitHub contributors wall), `/party`, `/house`, `/alignment`.
