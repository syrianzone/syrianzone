# Native adapter fixture

`adapter-fixture.tsx` registers a separate app entry. Neither production `index.ts` nor `App.tsx` imports it. Root temporarily bundles this entry into the simulator test application, runs only `NativeAdaptersUITests`, then restores the product bundle. It uses no account provider, API client, usage provider, persisted preferences or production mutation.

`testNativeSVGPixelDimensions` measures actual explicit and default-size `react-native-svg` output, then verifies the shipping `createSvgImageFile` path exports a displayed 80 by 40 SVG as exactly 160 by 80 PNG pixels. It checks real JPEG signature, dimensions and MIME type too. The original iPhone 17 run in `adapters-svg-red/result.xcresult` failed with actual 240 by 120 output for requested 80 by 40.

The pinned Bun patch changes only explicit SVG exports to renderer scale 1 and requested drawing bounds. Default-size export retains the old initializer and draw path, with a separate native fixture assertion. Independent JavaScript rounding is deliberately avoided because it changes viewBox geometry. The native encoder keeps separate 16 megapixel source/destination limits and provides real JPEG quality 0.9.

Actual `adapters-green-03` passed the native SVG/JPEG case with no failures or runtime warnings. Its copied 160 by 80 PNG passed the independent corner, orientation and circle check, including equal 46 by 46 white-circle extents. Expo58 file writes/copies/moves must be awaited before encoding or deleting sources. The first native green followed the sequencing fix.

The fixture retains only its generated geometry image at `Library/Caches/sz-adapter-svg-geometry.png`. Root copies that file from the task's simulator app container, then runs `bun native-tests/verify-image-geometry.ts /absolute/copied.png`. This checks four opaque full-bleed corners, red-top/blue-bottom orientation and equal white-circle extents. After copying, root may remove this one known fixture cache file. The checker reads actual output pixels and does not infer success from source text or dimensions alone.

`testHardwareKeyCommands` sends actual iOS XCTest keyboard events for `1` and the left arrow. The bare native Keys view is enabled only on the files tab while foregrounded. This verifies the native callback without adding a navigation provider or changing the shipping keyboard adapter.

Menu03 passed both native menu cases with zero failures, skips or runtime warnings. The controlled case passed in 22.9875 seconds, checking first/second/first selection, a single purpose label and the stable identifier. This verifies the shared menu binding and the observed long-value slot; other sizes, text settings and product workflows need their own evidence.

Native19 ran all 12 Search drawing checkpoints without loosening their assertions. The production SearchField retained the exact native and controlled query, real change callbacks, focus and layout evidence at all six stages. Root and the independent reviewer inspected all three production mixed-query screenshots: prefill, focused typing and ordinary blur showed no text crossing into the search icon. The prior clip-only comparator failed its mixed-query typing and blur checkpoints because `بحث` became `بح`. The native value and real Search callback already agreed on that missing `ث` before blur; geometry and focus matched. The bounded event history does not establish whether XCTest input delivery or native/React Native input handling caused the loss. The Search method failed, and the comparator's visible text overflow remains separate from that unattributed character loss. These screenshots do not establish every font scale, transition or query.

`testGeneratedFilesQuickLookAndCancelledShares` generates a one-pixel PNG and short text file in a unique cache directory. It checks native PNG conversion and actual ZIP central-directory paths, including a nested Arabic filename. It presents QuickLook and dismisses it, then presents and cancels the shipping SVG PNG, generated PNG and ZIP share sheets. The fixture removes its own cache files on unmount. It neither opens nor changes existing user documents.

Native19 separately passed both `NativeSaveControllerProbeUITests` cases: expanding the owned PNG's share actions and cancelling, and opening the observed Save-to-Files controller and cancelling. The probes bound the presented filename to their exact generated PNG and mount cache, then confirmed removal of that file and its empty owned cache directory. They did not select a storage provider or tap Save, create a Files folder, write a Files document or prove a final saved filename. The cohort had two passing Save observations and one failed Search method; it was not a full pass.

`createSvgImageFile` returns an owned temporary file. Every caller must delete it in `finally`. `shareSvgImage` and `shareSvgPng` already handle that ownership. The native source and destination images each have a 16 megapixel bound, and native path, file-byte, format and quality checks do not depend on JavaScript validation.

`testBareAudioPlaybackOwnershipBackgroundAndNativeSleep` uses the bare SyrianAudio owner with one existing allowed public EveryAyah HTTPS track. It checks real media advancement, pause and native listening-clock stability, resume, token replacement, background media advancement, native background sleep and release. The public track returned HTTP 200 and content length 831865 bytes during the read-only preflight. Availability remains external to this test.

The fixture reports received OS remote events through `adapter.status.remote`. It does not synthesize them. Lock-screen next/previous, physical headphone disconnects, interruptions and audible output remain unverified unless separately exercised. This test also does not prove Quran usage accounting, Quran provider enrichment, reader selection or account synchronization.

The bare audio and hardware-key tests passed in `adapters-green-02`. That run reported blocking audio-session activation/deactivation on main. The new serialized iOS27 asynchronous session adapter passed its full native lifecycle in `adapters-lifecycle-07` with no runtime warnings. That run also passed hardware callbacks, direct PNG/JPEG and SVG/JPEG. QuickLook still exposed no dismissal control after the image tap; the new native navigation container and explicit Done action need their own native green. Native SVG share cancellation already passed after the test adopted the real popover dismiss region.

If a native sheet uses a dismissal label outside English or Arabic, adjust the XCTest dismissal query using the actual accessibility tree. Do not infer success from a timeout or skip failed checks. Never bundle this entry as the shipping product.
