# Native iPhone review drafts

These 42 local drafts group the first-party catalogue, child screens, account pages and administration routes for a section-by-section phone review. They describe local implementation scope and recorded evidence. They are not a claim that every native action works. No GitHub PR, push, publication, deployment or production mutation was performed for these drafts.

Start with a conventional iPhone. Check the named behavior, loading/error states, keyboard, Arabic/RTL, light/dark appearance and accessible text before moving to larger or folding devices. Use isolated accounts for sign-in and writes. An opened heading proves navigation and initial rendering; forms, maps, exports and privileged actions need their own checks.

## Grouping boundaries

Saved, Settings, canonical/deep-link navigation, shared maps/permissions/layout and the global public campaign belong to the Home/shared-shell draft. Campaign editing is separate in site-popup-admin. Hotel details belong to hotels; the Muslim hub and its three child routes belong to muslim; all four local games belong to games. Directory admin routes stay with phonebook, syofficial, govapps or guesswho. Compass private pages belong to compass; Promises suggestion/detail/editor/review/speaker/sector routes belong to promises. Poll management lives in dashboard, while ballots/leaderboards live in tierlist. Source `/superadmin/login` opens account with mode=superadmin, `/superadmin` opens dashboard and UserResource list/create/edit belong to users-admin.

The 14 Board widgets are clock, weather, prayer, Quran, Pomodoro, notes, to-do, RSS, latest answers, today's events, guides, nearby places, transit cities and recipe of the day. Home/Board preserve recipe and answer previews, while food.syrian.zone and answers.syrian.zone remain sibling applications. Discord, the Flag Replacer store listing, Joory, Jard, its news site and President remain explicit external destinations. Their account, chat, extension or game code is not a missing first-party native section.

The FilamentInfoWidget framework logo/version/documentation/source links are intentionally excluded from the native product. Account/profile/logout and actual UserResource navigation are covered above. There are no additional unclaimed first-party screen groups in the audited catalogue and route inventories, while native control verification and backend rollout remain open.
